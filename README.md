اردو ڈائری | Urdu Diary 📖

اردو ڈائری is a privacy-focused, Urdu-first digital diary for writing, organizing, searching, and sharing personal notes with beautiful Urdu/Nasta'liq typography.

> اپنی بات، اپنی ڈائری، اپنی رازداری۔ 🔒



✨ Features

🇵🇰 Urdu-first interface with RTL support

✍️ Create, edit, save, and delete notes

🔎 Global search across notes

🕒 Created date and last edited date

💾 Local storage with IndexedDB

🔒 Privacy-focused, local-first design

🖼️ JPG export in portrait or landscape

📜 Long screenshot of complete notes

🏷️ اردو ڈائری watermark on generated images

📋 Copy and share note text

🎨 Urdu/Nasta'liq typography

👤 Save your name in Settings for a personalized welcome message

📱 Mobile-friendly design


🔐 Privacy

Urdu Diary is designed with a local-first approach.

Your diary notes are stored locally in the user's browser instead of being uploaded to a central notes database.

The application should not collect, upload, or share the contents of users' personal notes.

Important

Browser storage cannot guarantee permanent data preservation in every situation. Clearing site data, uninstalling/resetting the browser or device, or losing the device can result in data loss.

Urdu Diary is a static web application and can be deployed using platforms such as Cloudflare Pages.

Basic deployment:

1. Create a GitHub repository.


2. Upload the project files.


3. Connect the repository to your hosting provider.


4. Use the project root as the build/output directory.


5. Deploy.
